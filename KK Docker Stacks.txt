Tag new image (registry is working on a port 5000)
Tag the image and it will be added to docker images:

docker tag nginx localhost:5000/nginx
labex@ubuntu:~$ docker tag nginx localhost:5000/nginx

Connect to registry container to check the things - in case we want to see images where they been stored:

>docker exec -it registry /bin/sh  - connect to docker registry shell 

We have found the IMAGE in the DOCKER REGISTRY   (the full path is: /var/lib/registry/docker/registry/v2/repositories) !!!!
