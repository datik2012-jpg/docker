You saw how we first created a Docker network and then attached our containers to it.

Docker Compose simplifies this entire process by allowing us to define multiple containers, networks, ports, and environment variables inside a single compose.yaml file.

We will see this in action in the next task.

created docker compose.yaml

root@docker-host ~/clickcounter ➜  cat compose.yaml
services:
  redis:
    image: redis:alpine

  clickcounter:
    image: kodekloud/click-counter
    ports: 
      - "8085:5000"  

Run docker compose:

Note:
0.0.0.0:8085->5000/tcp . So in my pc i need to url from that port 8085 or how it works?

Yes, if you see a port mapping like 0.0.0.0:8085->5000/tcp in your docker ps output, it means that port 5000 inside the container is published to port 8085 on all network interfaces of your host machine.

To access the service running inside your container (on port 5000), you should use port 8085 on your PC. For example, if it's a web application, you would open your browser and go to:

http://localhost:8085
or

http://127.0.0.1:8085
