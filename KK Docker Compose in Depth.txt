////////////////Compose in Depth ///////////

docker run -d --name=redis redis
docker run -d --name=db postgres:9.4
docker run -d --name=vote -p 5000:80 voting-app
docker run -d --name=result -p 5001:80 result-app
docker run -d --name=worker worker

How they work together
These containers form a simple microservices architecture:

Redis → stores votes temporarily.

Postgres (db) → stores results permanently.

Voting app → frontend for submitting votes.

Result app → frontend for displaying results.

Worker → background processor moving data from Redis to Postgres.

Better solution create a network:

docker network create voting-net

Run container on network:

docker run -d --name=redis --network=voting-net redis
docker run -d --name=db --network=voting-net -e POSTGRES_PASSWORD=mysecret postgres:9.4
docker run -d --name=vote --network=voting-net -p 5000:80 voting-app
docker run -d --name=result --network=voting-net -p 5001:80 result-app
docker run -d --name=worker --network=voting-net worker

and  Docker links are deprecated.So do not use: docker run -d --name vote --link redis:redis voting-app
