Now network part ,lets create services:

redis-service.yaml

apiVersion: v1
kind: Service
metadata:
  name: redis
  labels:
    name: redis-service
    app: first-voting-app
spec:
  ports:
  - port: 6379
    targetPort: 6379
  selector:
    name: redis-pod            - this part is copied from redis yaml !!!!!!
    app: first-voting-app      - this part is copied from redis yaml !!!!!!

Load balancer , it will monitor votign app - so we can look voting web yaml and configure loadbalancer yml base on this:


voting-app-service.yml   - will be the name of the yaml for loadbalancer


apiVersion: v1
kind: Pod
metadata:
  name: voting-service
  labels:
    name: voting-service
    app: first-voting-app
spec:
  type: LoadBalancer  - need this type cause we want this service be accessible outside 
  ports:
  - port: 80
    targetPort: 80
  selector:
    name: voting-app-pod    - taken from voting app pod
    app: first-voting-app


LoadBalancer for results app as well we need:

apiVersion: v1
kind: Pod
metadata:
  name: result-service
  labels:
    name: result-service
    app: first-voting-app
spec:
  type: LoadBalancer  - need this type cause we want this service be accessible outside 
  ports:
  - port: 80
    targetPort: 80
  selector: 
    name: results-pod          - taken from results yml
    app: first-voting-app      - taken from results yml


Will start to deploy from voting app pod (web page part):

>kubectl create -f voting-app-pod.yml
Output: pod voting-app-pod.yml been created

Validate it running:

>kubectl get pods

Now lets deploy LoadBalancer for voting app web page:

>kubectl create -f voting-app-service.yml
Output: created !!

Validate services:
>kubectl get services
Output: Creating (need wait few minutes)

Now we can deploy Redis pod:
kubectl create -f redis-pod.yml
Output: Created

Validation:
>kubectl get pods
Output:Running

Now run Internal redis service:

kubectl create -f redis-service.yaml 
Output:Created

Validation internal redis service is running:
kubectl get services
Output: ClusterIP - is running

Create posgres pod:
