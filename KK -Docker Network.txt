//////////////////Docker Network ///////////

When we create network (not default created) will be created DNS 127.0.0.1 serevr which gives the option to containers creaetd in this netwrok to connect to each other by container name (ip not good idea cause 127.x.x.x ip addresss can be changed after container restart)

Step 1 — Create a custom network 
docker network create --driver bridge my-app

Step 2 — Run the MySQL container
docker run -d --name=mysql --network=my-app mysql

Starts a container named mysql.

Attaches it to the my-app network.

Other containers on the same network can connect using mysql:3306.



Step 3 — Run the web app container

docker run -d --name=web --network=my-app my-webapp


Starts a container named web.

Also joins the my-app network.

The web app can now connect to MySQL using the hostname mysql instead of an IP.

Why this setup matters
Container isolation — containers only talk to others on the same network.

Service discovery — Docker auto‑resolves container names.

Simplified configuration — no need for manual IPs or port mapping between containers.

Security — internal traffic stays off the host’s public interface.



Note: Docker compose always creates network defined:


version: "3.9"

services:
  mysql:
    image: mysql:8
    environment:
      MYSQL_ROOT_PASSWORD: secret
    networks:
      - my-app

  web:
    image: my-webapp
    depends_on:
      - mysql
    networks:
      - my-app

networks:
  my-app:
    driver: bridge


Run: docker compose up -d

Compose automatically:

Creates the my-app network (bridge driver).

Starts both containers.

Connects them to the same network.

Handles dependencies (depends_on ensures MySQL starts first).

Deploy a web application named webapp using the kodekloud/latest-webapp-mysql image.

Expose the container’s port 8080 to port 38080 on the host.

The application makes use of two environment variable:

DB_Host with the value mysql-db
DB_Password with the value db_pass123
Make sure to attach it to the newly created network called wp-mysql-network.


Note: We need to link the MySQL and webapp containers.


docker run -d \
  --name=webapp \
  --network=wp-mysql-network \
  -p 38080:8080 \
  -e DB_Host=mysql-db \
  -e DB_Password=db_pass123 \
  kodekloud/latest-webapp-mysql

Run:
