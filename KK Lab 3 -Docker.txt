Docker images are supposed to be small and light weight. Let us try to trim it down.

Build a new smaller docker image by modifying the same Dockerfile and name it webapp-color and tag it lite.


Hint: Find a smaller base image for python:3.14. Make sure the final image is less than 150MB.


So : python:3.14-alpine is about 50-60mb and python:3.14-slim 120–150 MB

Modify Dockerfile to have:

FROM python:3.14-alpine

RUN pip install flask

COPY . /opt/

EXPOSE 8080

WORKDIR /opt

ENTRYPOINT ["python", "app.py"]
